# 📊 Sales Dashboard Insights | Data Visualization Project

Welcome to the **Sales Analytics Dashboard Project** 🚀
This repository showcases an interactive dashboard designed to transform raw sales data into meaningful, actionable insights using data visualization techniques.

---

## 📌 Project Overview

This project focuses on analyzing sales performance across multiple dimensions to help uncover trends, patterns, and business opportunities. The dashboard enables users to explore key metrics and drill down into detailed insights through an intuitive and interactive interface.

💡 The goal: **Turn data into decisions.**

---

## 🎯 Key Features

### 🔍 Business Metrics at a Glance

* 💰 **Total Revenue Analysis** with trend indicators
* 📦 **Total Quantity Sold**
* 🧾 **Average Order Value (AOV)**

---

### 📅 Time-Based Insights

* 📈 Monthly sales trends to track performance over time
* ⏰ Hourly sales analysis to identify **peak sales hours**

---

### 🛍️ Product & Category Analysis

* 🏆 Top 5 performing products
* ⚠️ Bottom 5 underperforming products
* 📊 Category-wise contribution and transaction volume
* 📦 Product type breakdown for deeper insights

---

### 🌍 Location-Based Analysis

* 📍 Compare sales performance across different regions
* 🌐 Identify high-performing and low-performing locations

---

### 🎛️ Interactive Dashboard Features

* 🗂️ Dynamic filters (Month & Day selection)
* 🔄 Drill-down capabilities for deeper analysis
* 🧠 User-friendly design for seamless exploration

---
